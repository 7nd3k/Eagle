# Eagle

**Eagle** is a Python-based unit converter and formulas calculator tool designed for science and tech enthusiasts. It provides conversions for physical magnitudes, temperatures, masses, areas, volumes, and space-related formulas such as gravity, escape velocity, and energy.

---

## Features

- **Basic Magnitudes:** Length, mass, time, temperature conversions.
- **Physical Magnitudes:** Energy, velocity, density, and more.
- **Electromagnetic & Light:** Voltage, current, light units.
- **Scientific & Special:** Advanced scientific conversions.
- **Space Calculations:** Gravity, escape velocity, orbital mechanics.
- **User-friendly CLI:** Menu-driven interface using `pyfiglet` and `colorama`.
- **Supports scientific notation:** e.g., `1.1*10e24`.

---

## Installation

1. Clone the repository:

```bash
git clone https://github.com/7nd3k/Eagle.git
cd Eagle
```
2. Create a virtual environment for requirements
```bash
python -m venv venv # Create virtual environment for requirements

source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```
3. Install requirements and execute
```bash
pip install -r requirements.txt
python main.py
```
